# 初高中数学整理与验收计划

## 用户确认的范围

以本地人教版初中六册和人教 A 版高中五册的章、节、知识点为对照大纲。每项应有准确概念、公式或定理条件；关键方法应有可靠推导和代表性例题。课题学习可以用自编案例，不要求复刻教材例题与图形；课后习题不逐题录入。外部教材可用于交叉核验。

## 执行步骤

1. 以两份教材目录建立逐册清单，保留教材章节编号及对应博客专题。
2. 对每个知识点逐项核对定义、条件、推导和代表性例题，不以关键词出现作为完成标准；发现问题直接修改。
3. 为目录提供准确、可使用的专题入口，重新生成 HTML 和资料合集。
4. 检查推导、例题运算、生成页面和内部链接；记录尚未独立核验的内容。
