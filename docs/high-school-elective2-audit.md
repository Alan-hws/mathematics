# 高中选择性必修第二册：按小节核对

以人教 A 版目录为大纲，逐项对照博客中的概念、公式条件、关键推导和代表方法。N 指“不等式与数列”，D 指“复数与导数初步”；例题为自编。

| 目录条目 | 对照内容与正文位置 |
|---|---|
| 4.1 数列概念 | N“数列与求和”：下标、通项、递推和前 \(n\) 项和的区别。 |
| 4.2、4.2.1 等差数列概念 | N“数列、递推和数学归纳法”：公差、通项、由相邻差累加及例子。 |
| 4.2.2 等差数列前 \(n\) 项和 | N 同上：首尾配对、求和公式及 \(n\) 为正整数。 |
| 4.3、4.3.1 等比数列概念 | N 同上：首项与公比非零、负公比例子和通项。 |
| 4.3.2 等比数列前 \(n\) 项和 | N 同上：错位相减，\(q=1\) 单独处理；另有乘等比因子的求和例题。 |
| 4.4 数学归纳法 | N 同上：初始步骤、归纳假设和从 \(k\) 到 \(k+1\) 的证明。 |
| 5.1、5.1.1 变化率 | D“从变化率到导数及基本法则”：平均变化率和差商中 \(h\ne0\) 的条件。 |
| 5.1.2 导数与几何意义 | D 同上：极限存在、切线斜率和 \(x^2\) 的切线例题。 |
| 5.2、5.2.1 基本初等函数求导 | D“导数初步”“从变化率到导数及基本法则”：常数、幂、指数、对数、正余弦及各自条件；正整数幂从定义推导。 |
| 5.2.2 四则运算法则 | D 同上：和、积、商的可导条件和分母非零；积法则由差商推导。 |
| 5.2.3 简单复合函数 | D 同上：链式法则的例题，区分内外层。 |
| 5.3、5.3.1 函数单调性 | D“用导数判断单调性和闭区间最值”：按导数符号分区间，含三次函数例题。 |
| 5.3.2 极值与最值 | D 同上及“从变化率到导数及基本法则”：驻点不一定是极值，比较端点、内点及实际定义域。 |

额外补充 \(S_n\) 与 \(a_n\) 的首项检查、裂项和错位相减作为代表方法。记录不包含逐题转写课后习题；被标星的内容仍按目录列示。
