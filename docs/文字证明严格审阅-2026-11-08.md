## 审阅口径

按用户确认的要求，审查现有文字证明，补全逻辑缺口和依赖；不是 Lean、Coq 等机器证明，也不要求与某版教材的例题逐字一致。范围为初高中16章、高数18章、线代17章、概率统计20章；这些数字包括导读、资源、练习和学习记录，不是定理数量。速查表中的重复结论回到对应正文证明，不把重复抄写当作新的证明。

本轮在此前章节阅读基础上，检查证明的前提、量词、存在性、唯一性、正反方向、零值与退化情形、极限交换和依赖是否循环。原有公式、例题的逐行历史记录继续保留；新增段落的依据记为所在证明小节。自动脚本只核对台账与源文件一致性、选定恒等式和网站构建，不给全部数学正确性作机器认证。

## 证明依赖与适用边界

以下是引用的前提，不宣称在本库从公理重新证明。引用前提不等于逻辑缺口，但必须与实际使用的版本相符。

| 前提 | 使用位置 | 本轮检查的边界 |
|---|---|---|
| 经典逻辑、自然数归纳、有序域公理及实数完备性 | 代数、数列、极限和分析 | 公理/基础系统；不把交换律等当作由实例验证的定理 |
| 欧氏几何、坐标等距表示、面积可加与几何穷竭 | 初高中平面几何、圆面积 | 圆面积用内外接多边形逼近；避免先用依赖圆面积的三角求导再证明圆面积 |
| 单纯多边形三角剖分 | 一般多边形内角和 | 凸多边形扇形分割在正文说明；非凸简单多边形的剖分引理是额外依赖，不涵盖自交多边形 |
| π 的无理性 | 初高中实数分类 | 外部数论结论；圆周长定义不能证明无理性 |
| 有限维紧性、连续函数一致连续、连续函数空间完备性 | 最值、谱定理、逆函数、微分方程 | 使用闭有界有限维集或紧区间，不推广到任意无限维有界集 |
| 黎曼可积判据和积分的基本性质 | 定积分及积分应用 | 连续/分段连续的相应有界区间版本；不声称任意函数可积 |
| Fubini、Tonelli、单调收敛、支配收敛及可积函数逼近 | 多重积分、概率、傅里叶 | 交换积分或极限必须满足非负、绝对可积或支配条件；条件收敛不能任意交换 |
| 有限单位分解、零测集和广义换元 | 多元积分及概率密度变换 | 正文换元证明主要是C¹微分同胚与连续紧支撑函数；一般可测非负密度的版本另用Lebesgue换元定理，不假装已由紧支撑情形直接证明 |
| Radon–Nikodym/条件期望存在定理 | 条件期望 | 正文证明定义推出的性质及L²估计；一般存在性仍为外部依赖 |
