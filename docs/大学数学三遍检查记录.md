# 大学数学三遍检查记录

范围：高等数学、线性代数、概率统计三份知识文档，重点是本轮新增的 43 个初学者导读、例题、示意图及生成页面。此前初高中内容的本地未提交修改一并保留。

1. **概念与条件：** 逐章检查新导读的定义、例题及适用条件，并复核相关原有公式。修正连续函数变号与零点重数的错误表述，补充线性回归斜率分母条件、正态抽样分布的样本量和非退化条件，以及特征值为零时的几何含义。
2. **图文与学习顺序：** 核对极限、积分、线性变换、投影和概率分布示意图的标记与文中例子；修正极限图的直线位置和空心点叠放。补充 SVD、PCA、频率波动及双侧检验的计算例子。检查了图示的数值关系和 SVG 结构，但没有逐页进行浏览器视觉检查。
3. **生成与链接：** 重新生成专题页面及下载包，检查站内链接、目录入口、SVG 路径、下载包中的图片以及修改前后公式分隔符；用独立计算核验选定例题。详细命令与结果以本次运行输出为准。

这三遍检查覆盖了新增导读及与之相关的正文，不等于对三门学科的每一个历史公式、每一道旧练习都做了三遍独立证明或复算。外部链接没有逐一验证；MathJax 的实际浏览器渲染仍需联网页面的视觉检查。
