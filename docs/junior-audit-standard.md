# 初中数学核对标准

以本地人教版六册的章、节和知识点作为覆盖大纲，不要求讲解、插图和例题与教材逐字或逐图一致。课后习题不逐题录入。

每个知识点应核查：

1. 定义与符号是否准确，是否说明取值范围及适用条件。
2. 公式、定理、逆命题及判定是否成立，是否区分必要条件与充分条件。
3. 关键推导或证明是否成立，是否存在除以零、丢根、未经说明的假设等问题。
4. 代表性例题和课题学习是否与本节知识一致，计算与结论是否正确。
5. 补充知识可以参考可靠的开放教材、课程与其他资料，列明来源；不因教材 OCR 难以识别图形就将数学知识整体判为无法核对。

六册 `junior-grade*-audit.md` 是工作记录，并非逐小节核对已经完成的证明。旧记录中“需要回看原图”主要指章节标题、位置或原教材特定表达尚待确认；如可靠资料足以确认独立的数学结论，可据此补充博客，不必复制原图。缺少数学正确性核验或例题的条目仍应标为待处理。
