极限：无限接近不是“最后取到”

关键词：数列、函数、连续、ε-δ 语言

1. 直觉

考虑数列：1，1/2，1/3，1/4，……。它的每一项都大于 0，但项会越来越接近 0。这里的“接近”描述的是一个过程，而不是说某一项真的等于 0。

当 n → ∞ 时，1 / n → 0

极限关心的是：当自变量足够接近某个位置时，函数值是否会稳定地接近某个数。

2. 定义

如果对于任意给定的正数 ε，都能找到一个正数 δ，使得当 0 < |x − a| < δ 时，总有 |f(x) − L| < ε，那么称：

limx→a f(x) = L

这个定义强调两件事：x 不必等于 a；只要 x 足够接近 a，f(x) 就能任意接近 L。

极限的四则运算法则
若 lim f(x) = A，lim g(x) = B，则在分母极限不为 0 时：
lim(f ± g) = A ± B；lim(fg) = AB；lim(f/g) = A/B。

3. 连续

函数 f 在点 a 连续，需要同时满足：

  • f(a) 有定义；
  • limx→a f(x) 存在；
  • limx→a f(x) = f(a)。

直观上，连续意味着“靠近输入不会突然造成输出跳跃”。多项式、指数函数、三角函数在各自定义域内都是连续的。

4. 一个简单例子

直接代入无法计算下式，因为分子和分母都为 0：

limx→1 (x² − 1) / (x − 1)

因式分解得到 x² − 1 = (x − 1)(x + 1)。在 x ≠ 1 时，原式等于 x + 1，因此：

limx→1 (x² − 1)/(x − 1) = limx→1(x + 1) = 2

注意：极限只要求研究 a 附近的行为，不要求函数在 a 点本身必须使用原来的表达式有定义。

历史小记：古希腊的穷竭法已经在处理“无限逼近”的思想。阿基米德用不断内接、外切的多边形逼近圆，估计圆周率和面积。直到 19 世纪，柯西、魏尔斯特拉斯等人用严格的极限语言重建了微积分。

5. 记忆卡片

  • 极限描述的是附近的趋势，不一定等于函数在该点的值。
  • 连续性把“极限值”和“函数值”连接起来。
  • ε-δ 定义把“无限接近”变成了量化陈述。
  • 导数、积分、级数的严格定义都建立在极限上。
