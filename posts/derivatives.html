导数与中值定理：变化率的数学

关键词：切线、局部线性、单调性、极值、中值定理

1. 从平均变化率到瞬时变化率

如果物体在时间区间 [t, t+h] 内的位置从 s(t) 变为 s(t+h)，平均速度是：

平均速度 = [s(t+h) − s(t)] / h

当 h 趋近于 0，平均速度就逼近某一时刻的瞬时速度。这就是导数的来源。

f′(x) = limh→0 [f(x+h) − f(x)] / h

几何上，导数是曲线在某一点处切线的斜率；代数上，它是函数在该点的局部线性近似系数。

2. 常用求导法则

(xⁿ)′ = n xⁿ⁻¹　　(sin x)′ = cos x　　(eˣ)′ = eˣ
(f + g)′ = f′ + g′　　(fg)′ = f′g + fg′
[f(g(x))]′ = f′(g(x)) · g′(x)

最后一个公式是链式法则。它是反向传播、复合模型和多元微积分的基础。

3. 拉格朗日中值定理

定理：若函数 f 在闭区间 [a,b] 上连续，在开区间 (a,b) 内可导，则存在 ξ ∈ (a,b)，使得：
f′(ξ) = [f(b) − f(a)] / (b − a)

右侧是整段区间的平均变化率，左侧是某个中间点的瞬时变化率。定理说：只要函数足够光滑，平均变化率一定会在某处被“实现”。

4. 用导数判断函数行为

  • 若在区间内 f′(x) > 0，则 f 在该区间单调递增。
  • 若在区间内 f′(x) < 0，则 f 在该区间单调递减。
  • 若 f′(x₀)=0，x₀ 可能是极值点，也可能只是水平拐点。
  • 二阶导数反映斜率变化：f″(x) > 0 通常对应局部向上弯曲。

注意，f′(x₀)=0 只是极值的候选条件，不是充分条件。还需要检查导数左右符号或使用更高阶信息。

5. 一个例子：抛物线的最小值

设 f(x)=x²−4x+5。求导得 f′(x)=2x−4。令 f′(x)=0，得到 x=2；再由 f″(x)=2>0，可知此处取得极小值。

f(2) = 2² − 4×2 + 5 = 1

这类“建立目标函数 → 求梯度 → 找到驻点 → 判断性质”的流程，正是机器学习优化的基本原型。

历史小记：费马在研究极值问题时已经使用了类似导数的思想；牛顿把变化率用于力学和运动研究，莱布尼茨则发展出今天仍在使用的微分记号。两人的工作让导数成为描述自然变化的通用语言。

6. 记忆卡片

  • 导数是瞬时变化率，也是局部线性近似。
  • 中值定理把整体平均变化率和局部瞬时变化率联系起来。
  • 导数符号为 0 只能说明“可能”是极值点。
  • 梯度是多元函数导数的向量版本。
